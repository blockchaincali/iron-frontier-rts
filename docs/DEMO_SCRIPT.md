# IRON FRONTIER 90-second demo script

1. Open on the homepage and introduce the three battlegrounds and Recruit difficulty.
2. Start Guided Tutorial; recruit a rifle squad, select it, move, focus an enemy, and capture the nearest relay.
3. Show the 3D/2D switch, tactical minimap, smooth zoom, objective focus, and fit-to-battlefield controls.
4. Recruit a siege tank and rocket battery, then show projectile trails, impact effects, health feedback, and the orbital-strike impact.
5. Create a private room in a second browser, join by code, and point out the host-authoritative map and faction identities.
6. Issue a synchronized command, refresh the guest to demonstrate reconnect, then show victory and Play Again.
7. Close on the homepage hero and the line: “Command the frontier in a fast, cinematic 1v1 RTS built for the browser.”
